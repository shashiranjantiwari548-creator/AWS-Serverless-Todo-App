# AWS Serverless Todo App

This project is a Serverless Todo List Application developed as part of the 1Stop.ai Cloud Computing Internship.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- AWS Lambda
- Amazon API Gateway
- Amazon DynamoDB

## Features
- Add Todo

- Responsive User Interface
