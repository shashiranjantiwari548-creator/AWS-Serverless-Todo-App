# AWS Serverless Todo App

## Project Overview

This project is a Serverless Todo Application built using Amazon Web Services.

## Services Used

- AWS Lambda
- Amazon API Gateway
- Amazon DynamoDB
- HTML
- CSS
- JavaScript

## Features

- Add Tasks
- View Tasks
- Delete Tasks
- Fully Serverless Architecture

## Architecture

Frontend (HTML/CSS/JS)
        |
API Gateway
        |
AWS Lambda
        |
Amazon DynamoDB
